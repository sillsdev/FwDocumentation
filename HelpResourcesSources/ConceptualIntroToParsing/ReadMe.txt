# ConceptualIntroToParsing #

This folder contains all the source files for the Introduction to Parsing document available in FieldWorks under Help/Resources.

This document is to be edited in XMLMind XML Editor using XLingPaper.  (See https://software.sil.org/xlingpaper/.)
The output is generated as a PDF file and then checked in to:

> fwrepo\fw\DistFiles\Helps\WW-ConceptualIntro
